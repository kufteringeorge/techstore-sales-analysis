# TechStore Sales Analysis

## Описание проекта

Проект по анализу данных интернет-магазина электроники.
Цель проекта — исследовать продажи, выручку и основные бизнес-показатели с помощью Python.

## Используемые технологии

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Данные

Сгенерирован искусственный датасет из 20 000 заказов.

Данные содержат:
- информацию о клиентах;
- города;
- категории товаров;
- цены;
- скидки;
- способы оплаты;
- выручку.

## Проведенный анализ

Выполнен анализ:
- структуры данных;
- основных метрик;
- продаж по категориям;
- продаж по городам;
- самых прибыльных товаров;
- влияния скидок.
